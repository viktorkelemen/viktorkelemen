## Instruments & modular control

| Repository | What it does |
| --- | --- |
| [chordery](https://github.com/viktorkelemen/chordery) | Playable chord sets, alternate voicings, and WAV export in the browser. |
| [bohlen-pierce-explorer](https://github.com/viktorkelemen/bohlen-pierce-explorer) | Browser ES-8 interface with a Bohlen–Pierce motive sequencer. |
| [rene-web](https://github.com/viktorkelemen/rene-web) | Browser recreation of the René 2 Cartesian sequencer with MIDI output. |
| [selectbus-interface](https://github.com/viktorkelemen/selectbus-interface) | Control René 2 through Select Bus using an Expert Sleepers FH-2. |
| [zeroctrl](https://github.com/viktorkelemen/zeroctrl) | Eurorack sequencer inspired by Make Noise 0-CTRL. |
| [cv-cpp](https://github.com/viktorkelemen/cv-cpp) | C++/JUCE CV sender and sequencer experiments for DC-coupled interfaces. |
